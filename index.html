Activer le prix automatique

Quatre étapes, à faire une seule fois. Ensuite, le prix actuel de vos actions se met à jour tout seul.

  1. Ouvrez twelvedata.com/pricing et choisissez l'offre gratuite Basic. Aucun paiement n'est demandé.
  2. Créez votre compte avec une adresse e-mail et un mot de passe, puis confirmez votre e-mail.
  3. Une fois connecté, ouvrez votre tableau de bord : votre clé API y est affichée. Copiez-la.
  4. Collez-la ci-dessous et cliquez sur « Enregistrer et tester ».
Le compte gratuit couvre les actions américaines (NASDAQ, NYSE) : privilégiez le dollar. Les bourses européennes demandent un abonnement payant chez Twelve Data ; pour ces actions, vous pouvez toujours saisir le prix à la main. Seul le ticker est envoyé, jamais le contenu de vos analyses.
